# Adobe Growth City POC 1

A static interactive prototype for a PLG-inspired, sales-led SMB experience using Adobe Brand Visibility and CX Enterprise Coworker concepts.

## Run locally
Open `index.html` in a browser. No build process or server is required.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `adobe-growth-city-poc`.
2. Upload `index.html` and `README.md` to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will show the live URL after deployment.

## Edit
All copy, styling, data and logic are in `index.html`.
- Search for `Northstar Outfitters` to change the default company.
- Edit the CSS variables near the top to change colors.
- Edit the `src` array to change synthetic data sources.
- Edit the `ints` array to change interventions and impacts.
- Edit the seller view HTML to change briefing fields or scripts.

Because this is a POC, all data and impact estimates are synthetic and illustrative.
